01 — What it does

Three things, done properly.

No social feed, no streaks, no coaching voice. Apex builds the programme, runs the session, and keeps the record.

  • 01

    Build the programme

    Start from one of four hand-written templates, or let Apex generate a split around the muscles you want to prioritise and the time you actually have. Edit any of it afterwards.

  • 02

    Run the session

    Every set arrives pre-filled from last time. Tick it and the rest timer starts. Change a weight mid-session and the sets below it follow.

  • 03

    Keep the record

    Every set you complete is stored and becomes the baseline for next time. Your history stays on your phone and exports to a file whenever you want it.

02 — Programmes

Your split, or one built for you.

Pick a template and start, or answer three questions and let the generator do it — which muscles matter, how many days you train, how long a session can run. It rotates movements so you are not hammering the same pattern two days running, and it will not put a muscle on consecutive days.

03 — Progress

It changes the plan before you do.

Apex reads what you completed and sets the next session from it. Stall repeatedly and it does not simply repeat the weight: it moves to a different target, cuts the volume to let you recover, or offers a different movement altogether. Weekly sets per muscle are scored against what the research says actually grows it.
